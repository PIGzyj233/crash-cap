# Run anonymously on a trusted intranet

Phase 1 has no login, users, roles, or workspace permissions: everyone who can reach the platform can see and operate on all workspaces. The service must therefore remain on a trusted intranet or VPN and must not be exposed to the public Internet. Destructive Web/API operations and anonymous raw-binary download are excluded by default because the platform cannot attribute or authorize them.
