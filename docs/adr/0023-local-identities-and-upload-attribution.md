# 本地身份、上传归属与独立 Jira 凭据

内网 HTTP 平台从匿名协作切换为本地账号、服务端会话和只允许上传的平台令牌。人员自助注册，登录后全员跨空间协作；CI 通过独立凭据映射到固定服务账号。由于部署明确只提供 HTTP，Cookie 不启用 Secure，采用同源和 CSRF 校验并接受内网传输的信任前提；不把这些措施视为传输加密。

身份归属属于每次 Upload，不能属于去重后的 CatalogFile。上传者、后台执行者、人工审核者和问题负责人使用稳定用户 ID 分别记录；历史匿名数据显式归为未知，不推断真实用户。后续个人 Jira PAT 与本地认证解耦：平台令牌只存摘要，需向 Jira 转发的 PAT 未来另行加密保存。当前仅记录扩展契约，不引入 Jira 登录依赖或同步任务。

完整接口、部署和迁移规则见 [认证设计](../authentication.md)。本决定取代历史设计中的“禁止登录、用户表和身份接口”约束。
